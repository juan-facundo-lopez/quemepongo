# 👕 ¿Qué me pongo?

> **¿Qué me pongo?** es una **Progressive Web App (PWA)** diseñada para ayudar a las personas a decidir qué vestir en función del **clima**, el **momento del día** y su **estilo personal**.

---

## ✨ Descripción

Cada usuario puede iniciar sesión con su cuenta de **Google** y crear un **guardarropa digital** simplemente cargando fotos de sus prendas.

La aplicación utiliza **Inteligencia Artificial** para analizar cada prenda e identificar automáticamente información como:

* 👕 Categoría
* 🎨 Color
* 🧵 Material
* 🧥 Nivel de abrigo
* ✨ Estilo

Con esa información, la plataforma genera recomendaciones personalizadas para cada día.

---

## 🚀 Funcionalidades

### 👚 Guardarropa digital

* Inicio de sesión con Google.
* Carga de prendas mediante fotografías.
* Organización automática del guardarropa.

### 🤖 Análisis con IA

* Identificación automática de las características de cada prenda.
* Clasificación inteligente para mejorar las recomendaciones.

### 🌤️ Recomendaciones diarias

* Sugerencias de outfits según:

  * Clima actual.
  * Momento del día.
  * Prendas disponibles del usuario.
* Combinaciones alternativas para cada ocasión.

### 💡 Recomendaciones de compra

La aplicación detecta oportunidades para ampliar el guardarropa y sugiere qué tipos de prendas podrían aportar mayor versatilidad.

Además, el usuario puede guardar esas recomendaciones para consultarlas más adelante desde cualquier dispositivo.

## 🎯 Objetivo

Crear un asistente de vestimenta inteligente que combine **clima**, **guardarropa** e **Inteligencia Artificial** para simplificar la elección de qué ponerse cada día y ayudar al usuario a sacar el máximo provecho de su ropa.
