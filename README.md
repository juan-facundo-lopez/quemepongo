¿Qué me pongo? es una aplicación web progresiva pensada para ayudar a las personas a decidir qué vestir según el clima, el momento del día y su estilo personal. Cada usuario puede iniciar sesión con Google, cargar fotos de sus prendas y construir un guardarropa digital propio.  
La app analiza esas prendas para sugerir looks diarios, mostrar combinaciones alternativas y detectar qué tipos de ropa podrían sumar más opciones al armario. Además, incorpora análisis de imágenes con IA para identificar características de las prendas, como categoría, color, estilo, material y nivel de abrigo.  
También permite guardar recomendaciones de compras para revisarlas más adelante, sincronizándolas con la cuenta del usuario para que estén disponibles desde distintos dispositivos. El proyecto está desarrollado como una PWA, con una interfaz adaptable a celular y escritorio, backend en PHP/MySQL y autenticación mediante Firebase.
